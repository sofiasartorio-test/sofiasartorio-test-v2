# Damage Management & Certification Group

Sito web del gruppo DMC, Aerospace Structures & Materials, TU Delft.

Costruito con [Hugo Blox](https://hugoblox.com).

## Sviluppo in locale

    pnpm install
    hugo server

Il sito si vede su http://localhost:1313.

## Come aggiornare i contenuti

- Pagine: cartella `content/`
- Stili personalizzati: `assets/css/custom.css`
- Configurazione: `config/_default/`
